Project Details

Project Goals

Create a fully functional e-commerce platform with product listings, shopping cart, checkout process, and user accounts. The site should have a modern, responsive design and integrate with payment processors.

Technical Requirements

  • Angular 20 frontend with Material UI components
  • Node.js backend with Express
  • Non-relational database (MongoDB)
  • JWT authentication
  • Stripe payment integration
  • Responsive design for all devices
